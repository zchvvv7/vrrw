# 一、项目概述

## 1.1 项目背景

城市道路中存在施工锥桶、临时护栏、纸箱、轮胎、木板、散落货物、坑洼、事故占道物等风险。传统封闭集识别模型只能处理预先定义的类别，面对未知障碍物可能产生漏检。本项目拟建立“可行驶区域分割—已知障碍物检测—未知风险发现—空间冲突判断—风险预警”的车载视觉处理链路。

## 1.2 建设目标

• 实时输出道路可行驶区域及边界。

• 检测施工锥桶、路障、遗撒物、坑洼和静止占道物等已知风险。

• 发现训练类别之外、但真实占据道路空间的未知障碍物。

• 结合距离、自车速度和预计行驶走廊输出风险等级。

• 在夜间、雨雪、逆光和部分遮挡条件下保持可用，并正确输出降级状态。

## 1.3 责任边界

| **范围** | **内容** |
| --- | --- |
| 系统负责 | 图像接入、图像质量判断、可行驶区域分割、障碍物检测/分割、未知异常发现、距离与冲突计算、风险和日志输出 |
| 系统不负责 | 车辆制动/转向执行、完整路径规划、高精地图生产、道路基础设施控制 |
| 一期范围 | 单车前视视觉为主，结合自车CAN信号完成风险闭环 |
| 后续扩展 | 环视融合、BEV占用栅格、开放词汇模型及端侧部署 |

# 二、业务场景与系统范围

| **编号** | **场景** | **预期行为** |
| --- | --- | --- |
| SC-01 | 正常道路、井盖、阴影和道路标线 | 维持Safe，不产生频繁误报 |
| SC-02 | 施工锥桶或护栏改变可通行区域 | 重建可行驶区域并输出占道范围 |
| SC-03 | 车道内出现纸箱、轮胎或散落物 | 输出障碍物位置、距离和风险等级 |
| SC-04 | 出现训练集中未定义的异形物体 | 以未知异常区域输出，不因无法分类而漏报 |
| SC-05 | 暴雨、夜间或摄像头严重遮挡 | 输出Degraded/Unavailable，禁止维持虚假安全 |

# 三、系统总体需求

## 3.1 总体处理链路

视频与CAN同步接入 → 图像校正与质量检查 → 可行驶区域/道路结构分割 → 已知障碍物检测或实例分割 → 未知障碍物异常分割 → 距离估计 → 自车行驶走廊预测 → 空间冲突与风险计算 → 状态、接口和日志输出。

## 3.2 核心状态

| **状态域** | **建议值** | **说明** |
| --- | --- | --- |
| 系统可用性 | available/degraded/unavailable | 优先于业务风险输出 |
| 障碍物类型 | known/unknown/uncertain | 未知不等于低风险 |
| 空间关系 | outside/near/intersecting | 与自车预计行驶走廊的关系 |
| 风险等级 | safe/notice/warning/danger | 依据距离、速度、交叠和连续性判断 |

# 五、风险判定需求

| **等级** | **示例条件** | **输出建议** |
| --- | --- | --- |
| safe | 道路无异常或目标位于行驶走廊外 | 内部记录 |
| notice | 远距离可疑物体或异常分数较高但未稳定 | 视觉提示 |
| warning | 障碍物稳定存在且接近/部分侵入行驶走廊 | 显著提示并输出规控建议 |
| danger | 近距离障碍物侵入行驶走廊，剩余制动时间不足 | 强告警并向执行层输出高风险信号 |

# 六、接口需求

| **接口** | **关键字段** |
| --- | --- |
| 输入图像 | frame_id、timestamp、camera_id、image、intrinsics/extrinsics |
| 自车状态 | speed、acceleration、steering_angle、yaw_rate |
| 障碍物输出 | object_id、known/unknown、bbox/mask、confidence、distance |
| 风险输出 | corridor_overlap、risk_level、ttc、major_reason、system_status |
| 运行日志 | model_version、latency、dropped_frames、error_code |

# 七、非功能需求

| **类别** | **要求** |
| --- | --- |
| 实时性 | 在目标GPU和冻结分辨率下报告FPS、平均延迟和P95延迟 |
| 可靠性 | 单帧异常不直接触发高风险；连续帧结果需防抖 |
| 鲁棒性 | 覆盖夜间、雨雪、逆光、阴影、污损和遮挡 |
| 可维护性 | 模型、阈值、类别映射和场景参数配置化 |
| 可追溯性 | 输出关联数据版本、模型版本、配置和随机种子 |
| 安全性 | 感知不可用时明确降级，不输出虚假Safe |

# 八、验收指标

| **模块** | **建议指标** | **验收重点** |
| --- | --- | --- |
| 可行驶区域 | mIoU、IoU、Boundary F-score | 区域和边界同时评估 |
| 已知障碍物 | mAP、Recall、漏检率 | 高风险小目标优先看Recall |
| 未知异常 | AUROC、AUPR、FPR95、组件级Recall | 像素和实例指标结合 |
| 距离估计 | 绝对/相对误差、近距离分段误差 | 近距离单独统计 |
| 风险预警 | 事件Recall、误报/公里、提前量、抖动次数 | 不漏报和及时预警 |
| 系统性能 | FPS、平均/P95延迟、显存 | 固定硬件和输入条件 |
